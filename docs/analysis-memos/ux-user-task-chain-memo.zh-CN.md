## 用户研究摘要（20 条样本）

- **首次干预**：多在 **首条 turn 声称完成后**（非中途网络断）
- **情绪词**：「继续」「不对」「没按附件」「怎么又停」
- **达成 AGENTS「不让用户找 bug」**：交付类平均 **2.4/5**

## 文案/进度建议（非实现）

1. turn 成功但未 verified → 弱条「仍在生成文件，请稍候」
2. 自动续跑 → 「已从上次步骤继续（无需您操作）」
3. 阶段条显示 **当前子目标**（如「第 3/5 步：写入 .pptx」）而非工具名
4. 耗尽后 → 一条明确提问（Key/附件）而非「可能原因」列表
