# 设计功能 — 使用说明（非技术用户）

在 PilotDeck 对话里，用**日常语言**描述你想做的页面或稿子即可。系统会自动选用合适的设计流程。

**推荐提问手册（含可复制例句）** → [`open-design-prompt-examples.md`](open-design-prompt-examples.md)

**完整能力目录（类别 + 文件 + 提问 + 150 套设计系统）** → [`open-design-design-catalog.md`](open-design-design-catalog.md)（随接入更新，见文首维护说明）

---

## 1. 你能做什么

| 类别 | 举例 |
|------|------|
| 网站与产品页 | 官网、介绍页、定价、登录、后台、帮助中心 |
| 手机相关 | App 界面、新人引导 |
| 营销与传播 | 邮件版面、海报、多张社媒配图 |
| 内容与品牌 | 长文章、品牌故事、原则页、作品集 |
| 汇报与演示 | 横屏翻页汇报、季度数据页 |
| 办公与个人 | 更新说明、简历、升级付费页 |

完整例句见 [`open-design-prompt-examples.md`](open-design-prompt-examples.md)。

## 2. 怎么提问（三种方式）

### 方式 A：只说目标（最推荐）

例如：

> 帮我做一个在线健身 App 的介绍网页，要有标题、三个功能、价格和「免费试用」按钮，风格年轻清爽。直接开始做。

### 方式 B：附上你的材料

可同时提供：品牌色、Logo、参考截图、Word/提纲、旧版网页。并说明：

> 按我上传的样式做，不要大改结构。直接开始做。

### 方式 C：先要草图再要成品

例如：

> 先用灰框线稿搭官网结构，我确认后再做精美版。

---

## 3. 你会收到什么

- 可在浏览器打开的**网页文件**（保存在项目文件夹里）
- 简短说明：做了什么、还能改哪里
- 继续对话可只改一两处（例如「标题更大」「改成深色」）

---

## 4. 常见问题

**一直在问问题、不动手？**  
在句末加：`直接开始做，不要反复提问。`

**风格不对？**  
说明：`要简洁黑白风，不要紫色渐变背景。`

**想要 PDF？**  
生成后说：`告诉我怎么把这个网页导出成 PDF。`
