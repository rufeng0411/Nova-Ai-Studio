# 设计画布用户指南

## 查看与编辑

- **弹窗预览**里点「查看」：只读放大，不能改画布。
- 点「编辑」：弹窗会关闭，画布移到**右侧栏**；左侧对话仍可发消息。

## 常用操作

1. 拖拽、缩放：在 tldraw 画布上直接操作选中图片。
2. **矩形遮罩**：选中一张图 → 点「矩形遮罩」→ 以当前选区框作为修图区域。
3. **涂抹遮罩**：选中一张图 → 点「涂抹遮罩」→ 在图上涂抹需修图区域 → 「完成涂抹」保存到 `assets/mask-*.png`。
4. **发送到对话**：会带上矩形区域或涂抹遮罩路径。
5. **融合变体**：多选两张及以上图片 → 「融合变体」预填到输入框。
6. 流程图 / 脑图：添加 diagram 节点，Agent 可继续改源文件。

## 文件位置

画布保存在 `artifacts/canvas-时间戳/`：`canvas-manifest.json` + `assets/` + `diagrams/`。

## 开关

设置 → 设计画布。关闭后 SuperPreview 不再出现「查看/编辑」切换，不影响其它功能。

详细契约见 `docs/design-canvas-spec.zh-CN.md`。
