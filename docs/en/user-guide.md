# User guide

## Sign in

Unauthenticated visits go to `/login`. There is no register tab and no invite code. The only user is `admin`.

After login you always land on `/app`.

## Workbench

`/app` is chat plus deliverables.

## Hub

The Hub shows **400+** capability cards. Read the card first; use Try when you have a model key.

## Admin (this one operator)

Use platform models, MCP, skills, and hub visibility. `/admin/users` is not a multi-user console.

## Data

Control data lives in `.saas-dev-data/`. The engine may also use `~/.pilotdeck`. Keep both out of git.
