# Product overview (community edition)

**Nova Ai-Studio** community edition: deliver a whole project through conversation, on your own machine. Plain language in; Goal-Loop runs listen → analyze → set targets → produce → accept; reports, decks, pages, and video land in the project instead of a chat transcript.

Built for **one operator** who wants a local Agent workbench, keys and data under their control, AGPL-auditable source.

## What stands out

- `pnpm run dev` locally, one `admin`, SQLite in `.saas-dev-data/`
- Hub **400+**, **35** templates, SuperPreview **40+** formats (public wording; [digest](whitepaper.md))
- Token routing: up to about **70%** vs all-flagship, scenario-dependent, [claims](https://www.novapage.online/claims/)
- Eight domains — not marketing-only
- Unrelated to Amazon Nova / Nova Act

## Versus tools you already know

Chat UIs optimize fluent sentences. This repo optimizes files you can hand off, accepted against a checklist. Dify / FastGPT lean workflow builders and knowledge-base Q&A; Coze-class tools lean bot distribution. See [FAQ](faq.md) and the official [comparison](https://www.novapage.online/faq/#q-compare).

## What it is not

- Not a chatbot that only answers
- Not a node-graph you must draw before the first run
- Not a hosted chat that holds your keys by default

Team accounts or hosted options: [novapage.online](https://www.novapage.online/). Collab: README footer.
