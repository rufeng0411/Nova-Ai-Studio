# Product overview (community edition)

> Adapted from the official whitepaper ch. 1–2 and the product one-pager. Canonical enterprise text: [novapage.online/en/docs](https://www.novapage.online/en/docs/).

**Nova Ai-Studio 2.0** is an enterprise AI Agent platform driven by conversation. You state a goal; a Goal-Loop runs listen → analyze → set targets → produce → accept; files land in the project (reports, decks, pages, video), not only in chat.

Official site: [https://www.novapage.online/](https://www.novapage.online/)

## Who it is for

| Audience | Better entry |
| --- | --- |
| Leads who need a full file package | Official SaaS or private deploy |
| Teams sharing chats, files, and checklists | Official site |
| IT / compliance, multi-user or data residency | Official private deploy |
| One operator running the same workbench kernel locally | **This community repo** |

## What it is not (whitepaper 1.2)

- Not a chatbot that only answers
- Not a stack you must install before any use (hosted SaaS is browser-only; this community cut needs Node / pnpm on your machine)
- Not a single-vertical toy — office, research, creation, GEO, media, engineering, education
- Not locked to one public-cloud model vendor

## Public numbers

From the official whitepaper; do not turn them into SLAs:

- **400+** capabilities
- **35** workflow templates
- Tokens: up to about **70%** vs all-flagship on typical multi-step jobs ([claims](https://www.novapage.online/claims/))
- **40+** preview formats
- Eight Hub domains

## Community edition in one line

Same conversation engine and Hub, cut down to one admin + SQLite + local data. For teams and zero-install, use the official site.
