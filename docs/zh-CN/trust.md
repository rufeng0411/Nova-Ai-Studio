# 信任与数据（社区开源版）

> 企业安全全文：[官网白皮书第 8–9 章](https://www.novapage.online/docs/#s9)。本文只写本仓你能核对的事实，不把企业租户隔离写成社区版功能。

## 官网企业版（不要抄到本仓功能列表）

官网写的多层防护包括：多租户项目与记忆隔离、JWT、工具权限白名单、工作区沙箱、用量归属审计；SaaS 即用或 Docker / 物理隔离私有化。那是 [novapage.online](https://www.novapage.online/) 的企业叙事。

## 本仓社区版你可以核对的

| 项 | 事实 |
| --- | --- |
| 账号 | 仅 `admin`，口令来自 `SAAS_ADMIN_PASSWORD`，启动时必填 |
| 注册 | 关闭，接口 403 |
| 登录 | JWT（SaaS 模式） |
| 数据 | 默认 `.saas-dev-data/`，不进 git |
| 控制面库 | 黄金路径 SQLite（`DEV_SAAS_SQLITE=1`） |
| N2 Bot | 关闭 |
| 许可 | AGPL-3.0：通过网络提供修改版服务时需开放对应源码 |
| 遥测 | 产品安全审计口径为默认关闭；社区版不要假设有一份新的渗透测试报告 |

没有单独的「开源渗透测试白皮书」。需要给采购看的企业信任材料，请用官网白皮书，不要用本页冒充。

## Token 数字怎么引用

用官网指定句，并链 [claims](https://www.novapage.online/claims/)：「最高约 / 场景依赖」，不要写成无条件保证。
