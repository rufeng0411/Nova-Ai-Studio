## 1. Nova 是什么

Nova Ai-Studio 2.0 是用对话交付项目文件的 Agent 工作台。社区版把这套工作台跑在你自己的电脑上。

Goal-Loop：

**听需求 → 做分析 → 定目标 → 搞生产 → 严验收**

先听懂要什么，再拆成清楚目标，把文件写进项目文件夹；中途断了也能接着做。收尾不靠口头「做完了」，而是对照事先列好的成果清单：文件齐不齐、能不能打开。

智能路由：简单步骤走轻量模型、关键步骤再上旗舰。官方实测，在启用路由与模型池的典型多步骤交付里，相对全程旗舰直打，Token 费用最高约可节省七成；部分硬核编排可到约 1/6。**这是上限口径，不是 SLA。** 引用方式见 [Token 节省方法论](https://www.novapage.online/claims/)。

本仓是单人自托管：`pnpm run dev`、一个 `admin`、数据在本机。不知道怎么开口时用模板和能力中心。团队账号或托管方案见官网。

## 2. 具体能做什么

用平常说话发起任务，拿到可预览、可下载、能进项目文件夹的真实文件。

官网白皮书第 2 章列出的规模：**400+** 能力中心、**35** 条流程模板、最高约 **70%** Token 节省、**40+** 预览格式、**8** 个业务域。

八大业务域（官网）：办公演示、调查研究、营销飞轮、GEO·AI 搜索、创作设计、媒体投放、开发测试、教育学习。

一句话需求的例子（来自白皮书，不是虚构客户）：

| 你说 | 可交付 |
| --- | --- |
| 做一份带来源与图表的产业调研 | 综述、来源清单、图表包 |
| 把方案做成可编辑 PPT | 演示稿或幻灯图包 |
| 品牌全案：调研 + 策划页 + 社媒 | 全案目录与分平台成稿 |
| GEO 基线审计 | 审计清单 + 网页仪表盘 |
| 一稿多平台 | 分平台文案包 |
| 官网改成短宣传片 | 脚本 + 视频工程 |

社区版：能力卡片和模板在 Hub 里；**没有模型 Key 时可以看、不能完整跑**。团队协作交接包是官网能力。

## 3. 验收（SuperPreview）

官网第 7 章：启动即锁定成果清单；PDF、Word、PPT、Markdown、HTML、视频与代码等四十多种格式专业预览。假完成靠清单核对，而不是模型嘴上说完。

社区版工作台同样走成果清单 / 预览内核；以你本机跑起来的界面为准。

## 5. 信任

社区版数据默认在仓库旁 `.saas-dev-data/`，登录 JWT，单一管理员。企业租户隔离、用量大盘、私有化部署叙事见官网白皮书第 8–9 章与 [信任摘录](trust.md)。
