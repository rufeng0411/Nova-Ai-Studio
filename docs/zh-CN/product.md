# 产品总览（社区开源版）

> 正文改写自官网白皮书第 1–2 章与品牌 one-pager。完整企业说明以 [novapage.online/docs](https://www.novapage.online/docs/) 为准。

**Nova Ai-Studio 2.0** 是以对话驱动的企业级 AI Agent 平台。你用平常说话提需求，平台按 Goal-Loop 跑完：听需求 → 做分析 → 定目标 → 搞生产 → 严验收，把报告、PPT、网页、视频等文件写进项目，而不是停在聊天记录里。

官网主站：[https://www.novapage.online/](https://www.novapage.online/)

## 适合谁

| 人群 | 更合适的入口 |
| --- | --- |
| 业务 / 品牌负责人，要整套文件 | 官网 SaaS 或私有化 |
| 需要多人共享对话、文件和成果清单 | 官网（团队协作） |
| IT / 合规，数据要出公司边界或管多用户 | 官网私有化 / 企业安全章节 |
| 一个人想在自己电脑上跑同一套工作台内核 | **本仓库社区版** |

## 它不是什么（官网白皮书 1.2）

- 不是只能问答的聊天机器人
- 不是必须先装一堆客户端才能用的工具（官网站上打开浏览器即可；社区版需要你本机安装 Node / pnpm）
- 不是只做某一类工作——办公、调研、创意、GEO、媒体、开发、教育都覆盖
- 不是必须用某一家公有云算力——模型可接你自己的 Key 或公司模型服务

## 关键数字（对外口径）

以官网白皮书为准，引用时不要改成保证值：

- **400+** 能力
- **35** 条流程模板
- Token：典型多步骤交付相对全程旗舰直打，**最高约 70%**（场景依赖，见 [claims](https://www.novapage.online/claims/)）
- **40+** 预览格式
- 八大业务域

## 社区版一句话

同一套对话引擎和能力中心，裁成「单管理员 + SQLite + 本机数据」。要团队和免安装，请用官网。
