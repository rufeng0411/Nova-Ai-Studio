# 产品总览（社区开源版）

**Nova Ai-Studio** 社区版：在自己电脑上，用对话交付整个项目。平常说话提需求，Goal-Loop 跑完听需求 → 做分析 → 定目标 → 搞生产 → 严验收，报告、PPT、网页、视频写进项目，而不是停在聊天记录里。

适合：**一个人**想把 Agent 工作台跑在本机，Key 和数据自己管，源码可审计（AGPL）。

## 社区版特点

- 本机 `pnpm run dev`，一个 `admin`，SQLite 在 `.saas-dev-data/`
- 能力中心 **400+**、流程模板 **35** 条、SuperPreview **40+** 格式（对外口径，见 [白皮书摘要](whitepaper.md)）
- Token 智能路由：相对全程旗舰直打 **最高约 70%**，场景依赖，见 [claims](https://www.novapage.online/claims/)
- 八个业务域，不是只做营销
- 与 Amazon Nova / Nova Act 无关

## 和常见工具的差别

聊天窗口擅长把句子写顺。本仓要的是能发给别人的文件，并对照成果清单验收。Dify / FastGPT 更偏自建工作流和知识库；Coze 一类更偏 Bot 分发。选型对照见 [FAQ](faq.md) 与官网 [FAQ](https://www.novapage.online/faq/#q-compare)。

## 它不是什么

- 不是只能问答的聊天机器人
- 不是必须先画流程图才能开始的编排器
- 不是把 Key 默认交给别人托管的网页聊天

团队账号或托管方案见官网 [novapage.online](https://www.novapage.online/)，合作见 README 文末。
