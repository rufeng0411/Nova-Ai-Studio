# Word 文档 — 能力说明与提问示例（非技术用户）

在 PilotDeck 对话里**用大白话**描述即可。  
适合：**传播 brief、新闻通稿、正式备忘录、带标题层级的报告**等需要 **Word（.docx）** 交给客户或媒体的场景。  
网页、海报、PPT 动效请用「Open Design」类能力；本能力专注 **Word 文件**。

句末可加：**「直接开始做，做完告诉我文件路径。」**

> 管理员说明见 [`docx-admin-guide.md`](docx-admin-guide.md)

---

## 使用前请知道的三件事

| 事项 | 说明 |
|------|------|
| 能做什么 | 新建 Word、按你的内容排版（标题、段落、列表、页眉页脚等）、编辑已有 docx |
| 输出格式 | **.docx**，可用 Microsoft Word、WPS 打开编辑 |
| 与网页设计的区别 | 浏览器里看的 HTML 页面/海报 → 用 Open Design；**给客户/媒体的 Word** → 用本能力 |

---

## 一、传播 brief

| 复制提问 |
|----------|
| 帮我写一份【618 大促】传播活动 brief，输出 Word 文件，含背景目标、人群、核心信息、渠道节奏和交付物清单，直接开始做，做完告诉我文件路径。 |
| 给【新品发布】做一份对内传播 brief，Word 格式，要有 KPI、时间线和负责人占位，直接开始做。 |
| 根据下面要点生成 Word brief：【粘贴你的要点】，版式简洁专业，直接开始做，做完告诉我文件在哪。 |

---

## 二、新闻通稿 / 媒体稿

| 复制提问 |
|----------|
| 把下面内容整理成正式新闻通稿 Word：标题居中、导语、三段正文、文末媒体联系人，直接开始做，做完告诉我文件路径。【粘贴正文】 |
| 帮我写【公司名】发布【产品名】的新闻通稿，800 字左右，输出 docx，语气正式，直接开始做。 |
| 这篇通稿需要中英双语 Word 两个文件，结构一致，直接开始做，做完告诉我两个文件路径。【粘贴中文稿】 |

---

## 三、报告 / 备忘录

| 复制提问 |
|----------|
| 把这次 campaign 复盘整理成 Word 报告：摘要、数据要点、问题与下一步，带二级标题，直接开始做，做完告诉我文件在哪。【粘贴数据或要点】 |
| 写一份给客户的项目进展备忘录，Word 格式，一页以内，直接开始做。 |
| 把我上传/粘贴的内容改成正式 Word 报告版式（封面标题 + 目录占位 + 正文），直接开始做。【粘贴内容】 |

---

## 四、编辑已有 Word

| 复制提问 |
|----------|
| 打开项目里的 `artifacts/brief/xxx.docx`，把第三节改成【新内容】，另存为新文件，做完告诉我路径。 |
| 在这份 docx 里全局把「旧品牌名」替换成「新品牌名」，并更新页脚日期，直接开始做。 |

---

## 常见说明

- 没说清楚文件名或目录时，Agent 一般会放在项目的 `artifacts/` 下并告诉你完整路径。
- 若只要「能在浏览器打开的页面」，请改说「做 HTML 落地页/海报」，不要用 Word 能力。
- 第一次在本机使用前，维护者需在仓库根目录执行过 `npm install`（见管理员文档）。
