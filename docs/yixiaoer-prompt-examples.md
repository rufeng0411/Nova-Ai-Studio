# 国内社媒发布 — 能力说明与提问示例（非技术用户）

在 PilotDeck 对话里**用大白话**描述即可。  
**第一次使用**：需先在 [蚁小二网页](https://www.yixiaoer.cn/) 把抖音、小红书、公众号等账号绑定好；PilotDeck 里只需在 **设置 → 能力接入中心 → 社媒发布（蚁小二）** 填好 API 密钥。

句末可加：**「直接开始做，做完告诉我任务编号或结果摘要。」**

> 管理员说明见 [`yixiaoer-admin-guide.md`](yixiaoer-admin-guide.md)

---

## 使用前请知道的三件事

| 事项 | 说明 |
|------|------|
| 能做什么 | 查已绑定账号、上传素材、存草稿、发到平台草稿或公开、查发布进度与数据 |
| 不能做什么 | **不能**在对话里新绑抖音/小红书号（需去蚁小二网页扫码授权） |
| 默认安全策略 | 你没说「发布 / 上线 / 公开」时，应优先 **平台草稿** 或 **云端草稿**，避免误发 |

**两种「草稿」说法（别混）：**

| 你说的话 | 实际效果 |
|----------|----------|
| 「存到小红书/抖音草稿箱」 | 推到**平台 App 里**的草稿，可在 App 里再改 |
| 「先存蚁小二草稿 / 云端暂存」 | 只存在蚁小二后台，**不会**推到任何平台 |

若只说「存草稿」没说清哪一种，Agent 应向你确认后再做。

## 一、账号与权限

### 1. 查账号列表

**能干什么：** 列出你在蚁小二里已绑定的号；按平台、昵称、分组筛选；看哪些号登录正常、哪些掉线。

| 复制提问 |
|----------|
| 帮我查一下蚁小二里绑了哪些社媒账号，按平台列出来，直接查完告诉我。 |
| 看看有哪些账号登录失效或掉线了，把昵称和平台名告诉我。 |
| 我有哪些抖音号和小红书号？只要状态正常的，直接查。 |
| 查一下分组叫「品牌号」下面有哪些账号，直接开始做。 |

---

### 2. 更新账号设置（如出口网络）

**能干什么：** 给已有账号换团队代理、设置内置代理地区等（需管理员在蚁小二里配好代理资源）。**不能**用来新增账号。

| 复制提问 |
|----------|
| 帮我把蚁小二里昵称「XXX」的小红书号改成用内置代理，地区选上海，改完告诉我是否成功。 |
| 查一下团队里有哪些可用代理，再帮我把抖音号「XXX」绑到指定代理上。 |

---

## 二、素材与草稿

### 3. 上传图片 / 视频

**能干什么：** 把本地文件或已有链接里的图/视频传到蚁小二，拿到系统内的资源编号，供发稿使用。**不能直接填外链**当发布素材。

| 复制提问 |
|----------|
| 把这份文件上传到蚁小二：【本地路径或刚生成的图片路径】，上传完把资源编号告诉我。 |
| 用刚才做好的海报文件，先上传到蚁小二再准备发稿，直接开始做。 |

---

### 4. 登记到素材库

**能干什么：** 上传完成后，把资源登记进蚁小二素材库，方便团队复用。**必须先上传，再登记。**

| 复制提问 |
|----------|
| 把刚上传的那张图登记进蚁小二素材库，文件名写【春季海报】，直接做。 |
| 这段视频上传并入库到素材库，宽高时长按文件实际来，做完告诉我库里的记录。 |

---

### 5. 存蚁小二云端草稿

**能干什么：** 内容只保存在蚁小二后台，不推到任何平台；适合「先攒稿、以后再发」。

| 复制提问 |
|----------|
| 把下面这篇图文先存成蚁小二云端草稿，不要推到任何平台：【标题+正文+说明配图在哪】，直接做。 |
| 用刚才上传的素材，在蚁小二里暂存一份视频稿，标题是【XXX】，不要发布。 |

---

## 三、发布内容（图文 / 视频 / 长文章）

支持多平台（小红书、抖音、公众号、B 站、微博等 50+），分三种内容形态：

| 形态 | 典型平台 | 你对话里怎么说 |
|------|----------|----------------|
| 图文 | 小红书、抖音图文、微博等 | 「一篇图文笔记」「几张图+标题」 |
| 视频 | 抖音、快手、视频号、B 站等 | 「一条短视频」 |
| 长文章 | 公众号、头条号、百家号等 | 「一篇长文/公众号文章」 |

### 6. 发到平台草稿箱（推荐默认）

**能干什么：** 内容推到对应平台 App/后台的**草稿箱**，你可在 App 里再审一遍再点发布。

| 复制提问 |
|----------|
| 把这篇图文存到小红书草稿箱，不要公开发布，账号用【昵称】，标题【XXX】，配图用刚才上传的，直接做，做完告诉我任务编号。 |
| 用刚才生成的 9:16 海报，发到抖音草稿箱，不要上线，标题和描述如下：【…】 |
| 这篇公众号长文先推到公众号草稿箱，不要群发，直接开始做。 |
| 把这条视频发到 B 站草稿，账号【XXX】，标题【XXX】，视频文件用刚上传的，不要公开。 |

---

### 7. 公开发布（需明确说明）

**能干什么：** 按你的确认，向指定账号**直接发布**（仍建议先发草稿验一遍）。

| 复制提问 |
|----------|
| 我确认要公开发布：发到小红书账号「XXX」，标题【XXX】，正文【XXX】，配图【说明路径】，请执行正式发布。 |
| 把这条视频在抖音号「XXX」上公开上线，标题和话题如下，我确认可以发。 |

> 未出现「发布 / 上线 / 公开 / 群发」等词时，应按草稿处理。

---

### 8. 发布前先查平台选项（分类、话题、位置等）

Agent 在组稿前常会查这些；你也可以主动要求：

| 能力 | 能干什么 | 复制提问 |
|------|----------|----------|
| 分类 / 栏目 | 查该号可选发文分类 | 查一下小红书账号「XXX」发图文有哪些分类可选，列给我。 |
| 征文活动 | 查平台征文 | 看看公众号账号「XXX」有没有可参加的征文活动。 |
| 地理位置 | 查 POI 打卡点 | 帮抖音号「XXX」搜一下和【深圳南山】相关的定位列表。 |
| 背景音乐 | 查抖音/快手 BGM | 给抖音号「XXX」搜背景音乐，关键词【治愈】，列几条可选。 |
| 音乐分类 | 查 BGM 分类 | 查一下该抖音号可选的音乐分类有哪些。 |
| 合集 | 查已有合集 | 列出视频号「XXX」里已有的合集，我要挂到新视频上。 |
| 群聊 | 查可挂载群聊 | 看看这个视频号能挂哪些群聊。 |
| 商品 | 查可挂载商品 | 查小红书号「XXX」能关联哪些商品。 |
| 热点 | 查平台热点 | 看看抖音号「XXX」当前有什么热点可蹭。 |
| 话题挑战 | 查话题/挑战 | 帮我在快手号「XXX」搜和【美食】相关的话题挑战。 |
| 小程序 | 查可挂小程序 | 列出该号发布时能挂载的小程序。 |
| 同步账号 | 查可联动发布的关联号 | 看看这个号有没有可同步一起发的关联账号。 |
| 游戏 | 查可挂载游戏 | 查该账号能挂载的游戏列表。 |

## 四、发布任务与数据

### 9. 查发布记录（任务列表）

**能干什么：** 看最近发了哪些单、成功失败概况。

| 复制提问 |
|----------|
| 查一下蚁小二里最近 10 条发布任务，按时间倒序，告诉我摘要。 |
| 看看今天有没有失败的发布任务，把失败原因概括给我。 |

---

### 10. 查某一单详情

**能干什么：** 根据任务编号看每个平台、每个账号的执行明细。

| 复制提问 |
|----------|
| 任务编号是【XXX】，帮我把这单的详细状态和每个账号的结果查出来。 |
| 查一下刚才那单「存小红书草稿」的任务进行到哪了，直接查完告诉我。 |

---

### 11. 账号数据汇总

**能干什么：** 看某段时间内账号整体表现（阅读、互动等，以蚁小二返回为准）。

| 复制提问 |
|----------|
| 查一下小红书账号「XXX」最近 7 天的数据汇总，直接给我结论。 |
| 把我所有抖音号上周的表现拉个表，看哪个号互动最好。 |

---

### 12. 单条作品数据

**能干什么：** 查某篇已发作品的数据表现。

| 复制提问 |
|----------|
| 查一下最近发的那条小红书笔记的数据表现，把阅读、点赞、收藏告诉我。 |

---

## 五、网络代理（团队功能）

### 13. 查代理资源

**能干什么：** 列出团队可用代理、内置代理地区编码，供绑定账号或排查云发布失败。

| 复制提问 |
|----------|
| 查一下我们团队在蚁小二里配置了哪些发布代理，列个清单。 |
| 内置代理有哪些可选地区？我要给新账号配出口 IP。 |

## 六、和设计 / 视频能力联用

先做好物料，再发稿：

| 步骤 | 复制提问 |
|------|----------|
| 1. 做图 | 帮我做一张【活动】竖版海报 9:16，直接开始做，做完告诉我文件在哪。 |
| 2. 发稿 | 用刚才做好的海报，存到小红书草稿箱，不要公开发布，账号【XXX】，直接做，做完告诉我任务编号。 |

| 步骤 | 复制提问 |
|------|----------|
| 1. 做视频 | 帮我把这段 HTML 转成 8 秒产品开场视频，直接做。 |
| 2. 发稿 | 把刚生成的视频上传到蚁小二，发到抖音草稿箱，标题【XXX】，不要上线。 |

## 七、能力一览（对照表）

PilotDeck 已接入、可通过对话触发的蚁小二能力如下（**不含**网页绑号）：

| 能力 | 能干什么 | 典型提问关键词 |
|------|----------|----------------|
| 查账号 | 列账号、查掉线 | 有哪些号、失效、掉线 |
| 更新账号 | 绑代理等 | 换代理、出口 IP |
| 上传素材 | 图/视频进系统 | 上传、传到蚁小二 |
| 素材库 | 团队素材登记 | 入库、素材库 |
| 云端草稿 | 仅蚁小二暂存 | 蚁小二草稿、云端暂存 |
| 平台草稿 | 推到 App 草稿箱 | 小红书草稿、不要公开 |
| 公开发布 | 直接上线 | 确认发布、公开、上线 |
| 分类/活动/POI 等 | 发稿前选项 | 分类、话题、定位、BGM |
| 发布记录 | 任务列表 | 最近发布、失败任务 |
| 任务详情 | 单笔进度 | 任务编号、状态 |
| 账号/作品数据 | 运营复盘 | 数据、表现、7 天 |
| 代理查询 | 团队网络 | 代理、地区 |

## 八、说明与免责

- 各平台必填项不同（标题、分类、封面比例等），Agent 可能多问你一两句，属正常。
- **公开发布前请自己在 App 里再核对**；默认优先草稿。
- 海外平台（LinkedIn、X 等）规划走 Postiz，与蚁小二国内矩阵分工不同。
- 绑号、续期登录仍需 [蚁小二网页](https://www.yixiaoer.cn/) 或客户端；PilotDeck 负责在账号就绪后的查询与发稿。
