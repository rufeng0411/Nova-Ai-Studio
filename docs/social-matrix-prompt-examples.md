# 一条创意发全平台 — 提问示例（非技术用户）

在 PilotDeck 对话里**用大白话**说你要做什么即可。  
需要先能在对话里**出图**（在设置里配好图片能力），若要自动推到抖音/小红书等，还要配好**社媒发布**密钥并在蚁小二网页绑好账号。

句末可加：**「直接开始做，做完告诉我文件夹在哪。」**

> 管理员配置见 [`social-matrix-admin-guide.md`](social-matrix-admin-guide.md)  
> **新手从策划到发布（含蚁小二四平台）** 见 [`social-matrix-beginner-walkthrough.md`](social-matrix-beginner-walkthrough.md)

---

## 只做文案 + 配图（不发布）

| 复制提问 |
|----------|
| 我有一条春季新品宣传创意，帮我按抖音、快手、小红书、微博、知乎、头条、百家号、视频号各写一版标题和正文，并生成竖版、方图、横版、小红书笔记四种尺寸的配图，先不要发布，直接开始做，做完告诉我文件在哪。 |
| 主题是「办公室护眼灯」，语气偏干货，只要小红书和抖音两个平台，配图要 9:16 和 3:4，文案矩阵和图都打包好，不要上线。 |
| 同一条活动话术，帮我出四套不同比例的 AI 图，再按国内主流图文平台改标题和话题，存到项目文件夹里就行。 |

---

## 要小红书多图轮播（可选）

| 复制提问 |
|----------|
| 在上面基础上，再帮我做 5 张可左右滑的小红书系列图页面（HTML），和 AI 配图放在一起，仍然不要发布。 |

---

## 做完后要存草稿（需已配发布能力）

| 复制提问 |
|----------|
| 矩阵包做好后，把小红书和抖音的图文**存到对应 App 草稿箱**，不要公开发布，做完告诉我任务结果。 |
| 先把图文存到蚁小二云端草稿，我稍后在后台自己点发布。 |

## 使用前请知道

| 事项 | 说明 |
|------|------|
| 会得到什么 | 一个文件夹：各平台文案表、清单文件、四套比例配图 |
| 默认行为 | 你没说「发布 / 上线 / 公开」时，**只生成文件**，不会自动发帖 |
| 平台名称 | 用中文：抖音、快手、小红书、新浪微博、知乎、头条号、百家号、视频号 |
