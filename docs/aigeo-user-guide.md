# AI 搜索可见度 — 使用说明

在 PilotDeck 对话里，用日常语言说明你的**品牌/产品**和想被 AI 推荐到的场景即可。系统会自动做可见度策划、成稿、评分与验证说明。

**可复制例句** → [`aigeo-prompt-examples.md`](aigeo-prompt-examples.md)

---

## 1. 你能做什么

| 能力 | 举例 |
|------|------|
| 可见度审计 | 清单式检查：内容是否容易被 AI 引用 |
| 关键词与验证问句 | 「用户会问 AI 哪些问题」 |
| 多平台成稿 | 知乎、小红书、公众号等结构化稿件 |
| 内容评分 | 0–100 分与改进建议（需环境就绪） |
| 提及验证 | 模拟或真实查询里是否提到品牌 |
| 周报 | HTML 数据向可见度报告（可选） |

---

## 2. 三种开始方式

### 方式 A：能力中心（推荐）

1. 打开 **能力中心** → **策略策划**
2. 找到 **「AI 搜索可见度全案」**
3. 点 **试一下**，按提示填【品牌】等占位后发送  
   或句末加：`直接开始做，做完告诉我文件在哪。`

**监测向快检**：能力中心 → **监测复盘** → **「AI 搜索优化（GEO）」**（审计清单）。

### 方式 B：流程模板

输入框或空态 → **流程模板**：

- **AI 可见度快检**（2 步，最快）
- **AI 搜索可见度标准包**（4 步，常用）
- **品牌 GEO 全案**（含 Schema、可选存草稿）

点 **试一下** 即可注入整段任务说明。

### 方式 C：直接说话

例如：

> 帮我的品牌【XX】做 AI 搜索可见度：关键词、一篇知乎稿、评分和验证计划。直接开始做，做完告诉我文件夹路径。

---

## 3. 你会收到什么

文件一般在项目里的 **`artifacts/geo/你的主题/`**：

- 审计清单、关键词表、成稿、优化稿
- 评分与验证结果（JSON + 可读的 report）
- 可选 HTML 周报

对话里会显示缩略/链接；可在右侧预览 Markdown、JSON。

---

## 4. 常见问题

**一直在问问题、不动手？**  
句末加：`直接开始做，不要反复提问。`

**没有 0–100 分？**  
可能评分服务未配置，仍会给你**清单版评估**（`score-estimate.md`），对话会温和提示，不中断。

**验证写着 mock？**  
表示未配置可选的联网验证 Key，会给出待人工核查的问句列表。

**和发小红书的关系？**  
全案模板可把成稿存**草稿**；不配置蚁小二则跳过发布，只保留本地文件。
