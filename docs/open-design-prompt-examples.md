# 设计助手 — 提问示例（给非技术用户）

在对话里**用大白话描述你要什么**即可，不必记任何内部名称。需要更快出稿时，可在句末加：**「直接开始做，做完告诉我文件在哪。」**

> 完整目录（所有类别、对应文件、150 套品牌风格与提问句式）：[`open-design-design-catalog.md`](open-design-design-catalog.md)  
> 接入新能力后请与本文档一并更新（见该文首「维护说明」）。

## 一、最常用（优先看这里）

| 你想做的 | 复制这句话（把【】改成你的内容） |
|----------|----------------------------------|
| 产品官网 / 介绍页 | 帮我做一个【在线教育 App】的介绍网页，要有醒目的标题、三个核心功能、价格或试用按钮、页脚联系方式。风格简洁专业，直接开始做。 |
| 硬件产品页（用官网真图） | 请帮我完成「高品质前端界面设计」：【华硕 ROG NUC 5080】。图片必须用官网实际大图，不要 AI 生成。直接开始做，做完告诉我文件在哪。 |
| 登录 / 注册 | 帮我设计【会员网站】的登录、注册和收验证码三个页面，风格干净，紫色主色，直接开始做。 |
| 版本更新说明 | 帮我做一页【2.3 版本】更新说明，写清楚新功能、修复的问题、升级要注意什么，适合发给用户，直接开始做。 |
| 价格与套餐 | 帮我做【团队协作软件】的定价页，三个套餐（基础/专业/企业），对比能做什么，企业档写「联系销售」，直接开始做。 |
| 后台 / 数据面板 | 帮我做一个【电商运营】后台首页，左边菜单、上面几个关键数字、下面销售趋势图（示例数据即可），直接开始做。 |
| 手机 App 界面 | 帮我画【记账 App】的手机界面，首页、记账页、统计页三屏并排展示，像真手机一样，直接开始做。 |
| 新用户第一次打开 | 帮我做【健身 App】新人引导，三屏：欢迎、有什么好处、注册或开始，直接开始做。 |
| 活动邮件 | 帮我做一封【春季促销】邮件版面，有标题、主图位置、活动说明和「去购买」按钮，能在邮件里正常显示，直接开始做。 |
| 小红书 / 多张配图 | 帮我做【时间管理】主题 5 张配图，能左右滑动，每张一个要点，风格统一，适合发社交平台，直接开始做。 |
| 汇报 / 路演幻灯片 | 帮我做【10 页】公司季度汇报，杂志风、横着翻页、每页一屏不滚动，含封面、成绩、问题、下季度计划，直接开始做。 |
| 常见问题 | 帮我做【云存储产品】帮助中心，能搜索、分「账号/付费/使用」三类，每类 4 个常见问题，直接开始做。 |
| 长文章阅读页 | 帮我把下面提纲做成好看的阅读页：【粘贴你的章节标题与要点】。杂志排版，直接开始做。 |
| 活动海报 | 帮我做【周末市集】竖版海报，时间地点写清楚，三条亮点，底部留二维码位置，直接开始做。 |
| 先搭页面结构 | 帮我用灰框线稿搭一个【企业官网】结构：首页、关于、产品、联系，先不要精美配色，直接开始做。 |

## 五、说不清类型时

```text
我想给【目标人群】做一个【网页/手机页/汇报/海报】，用来【达到什么目的】。
风格想要【例如：简洁、温暖、严肃、像杂志】。
必须包含【列出 3～5 个模块或信息】。
品牌主色是【可选】。
直接开始做，做完保存成能打开的网页并告诉我路径。
```

---

## 六、提高成功率的三个小技巧

1. **说清对象**：给谁看（客户、老板、用户、求职者）。
2. **说清模块**：至少列出 3 个必须出现的区块或信息。
3. **说清约束**：例如「不要暖棕色大面积背景」「不要编造我们公司没提供的数字」。

## 七、一键出图片 / 视频（已支持在 PilotDeck 内完成）

现在可以直接在 PilotDeck 对话里说「生成 png / mp4」，不必跳到外部应用。

### 先配一次（管理员做）

在 `~/.pilotdeck/pilotdeck.yaml` 里配置图片/视频能力（示例）：

```yaml
tools:
  image:
    provider: openai-compatible
    apiKey: ${OPENAI_API_KEY}
    baseUrl: https://api.openai.com/v1
    model: gpt-image-1
  video:
    provider: openai-compatible
    apiKey: ${OPENAI_API_KEY}
    baseUrl: https://api.openai.com/v1
    model: sora
```

### 直接可复制提问

**出图示例：**

```text
帮我生成一张竖版活动海报：周末市集，时间周六下午两点，地点市中心广场，三条卖点，清新手绘风。直接输出 png 文件。
```

**出短视频示例：**

```text
帮我做一段 8 秒的产品开场视频：咖啡订阅 App，温暖叙事，横屏。直接输出 mp4 文件。
```

**HTML 动效转视频示例：**

```text
我有一份动态网页，请把它导出成 16:9 的 mp4 宣传视频。
```

### 可视化访问

- 写出 `.html` 后，聊天页右侧会出现实时预览面板。
- 写出 `.png/.mp4` 后，工具结果会显示文件，可直接点击打开。

### Figma 自动化

如需在 Figma 自动处理设计稿，请让管理员先在 MCP 里配置 Figma 服务，再在对话里说明「读取这个 Figma 文件并…」。
