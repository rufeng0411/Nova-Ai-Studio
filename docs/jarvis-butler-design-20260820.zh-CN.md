## 1. 你要确认的结论

贾维斯不是第四套会写 PPT 的 Agent。他是**每用户一条**沟通入口：

- 左边：跟他说话（打字或实时语音），只留当前一句，不是对话流水账
- 右边：任务管理与监控（进行中 / 等你 / 排队 / 计划）
- 中间：他派人去现有工人会话里把专业活干完

用户不管理会话列表、不盯过程时间线。缺额度、外发才问你。管家会话**永不**编译成果清单。

形象：电蓝光核圆徽。中文 **贾维斯**。英文界面 **Steward**。

**只有这一版布局**（左沟通 / 右手头）。不做 v1/v2/v3。

设计已确认。落地走实现计划卡。

---

## 2. 为什么这样做

现网里「任务」就是一条对话。没有独立任务表。跨对话并行靠 Turn Queue（默认 7）。计划任务是 Cron + Always-On，和 Hub 能力不是一条链。完成没有 Push。Subagent 禁止代写成果。

竞品可学的是主从（Manus）、对话里订计划（ChatGPT Scheduled）、贵操作要许可（Cowork）。不要另造虚拟电脑，不要独立 Operator 站。

Nova 差异：工人会话就是用户已经会用的对话。

```
你 → 贾维斯 HUD（无成果契约）
        ├─ 问进度 / 闲聊 → 管家自己短答（幂等，不新开工人）
        ├─ 去做某事 → accept 管线 → 工人会话（完整成果契约）
        └─ 订个点 → 计划任务（fire 时带上能力上下文）
工人验收 / 需你 / 计划跑完 → 右侧手头 + 圆徽变态（你在工人里时不插嘴）
```

---

## 3. 审阅锁死

1. Hub「试一下」禁止绑到管家会话。只变成口令，再开工人。
2. 管家零 SDM、零 STDA、零成果修复、零「成果清单」。右侧叫「手头」。
3. 贾维斯是工作台首页：左沟通、右手头。不是侧栏里又一条聊天，不做多版布局。
4. 默认不展示对话记录。当前一句 + 你刚说的一行即可。任务状态只在右侧。
5. HUD 主核用满八态。别处 18px 只显示 idle / active / needs_you。
6. 打断管家说话（再开口或停）不停工人。停某件用右侧暂停。「都停」才全停。
7. 回访有任务时第一句报数，禁止每次「在。」
8. 不画贴纸键盘。表情只在圆徽上。
9. 右侧不是任务文件夹，禁止回退整棵项目树。
10. 你在工人会话里时，贾维斯不往工人气泡插话。
11. 不把 Loading 极光铺满工作台。主核可借轨道、声波环、准星刻度。
12. 用户少点：派活、问进度、点「处理」（仅缺额度等）即可。排队与推进由他完成。

## 4. 角色

**是**：首席调度。听懂 → 开或续工人 → 盯 → 报。

**不是**：自己写成果的工人、能力中心导购、客服、全屏全息。

性格：先结论后半句；短、稳、干；有「我」；不叫主人 / Sir；不卖萌；不恐慌红墙；不问卷开场。

### 口头禅

| 时机 | 中文 | 英文 UI |
|------|------|---------|
| 空闲 | 在。说要做的就行。 | Here. Say what you need done. |
| 回访 | 三件事在做，一件等你。 | Three running, one needs you. |
| 收下 | 收到，我来安排。 | On it. |
| 已派 | 已经在做了，你不用守着。 | It's running. You don't have to watch. |
| 排队 | 前面还有两件，我帮你排上了。 | Queued. Two ahead of you. |
| 进行 | 还在写，两份还没齐。 | Still writing. Two files not in yet. |
| 完成 | 搞定。成果在任务文件夹里。 | Done. Files are in the task folder. |
| 需你 | 卡在额度上了。你点一下，我接着做。 | Stuck on quota. You tap, I continue. |
| 计划 | 每天九点竞品简报。跑完我会叫你。 | Competitor brief at 9. I'll call you. |
| 进度 | 还在做，没有停。 | Still going. It hasn't stopped. |

管家过程占位覆盖「好的，请稍等」→「收到，我来安排。」工人会话不改。

禁止对用户说：PilotDeck、交付物、SDM、skill 名、错误码、「系统正在处理您的请求」。

## 5. 形象与动效

三层 SVG：电蓝晕 + 实心核 + 带缺口内环（表情）+ 两点外轨卫星。

深浅两套透明度。浅色核用 `217 90% 48%` 加深一点保证对比；暗色 `217 100% 65%`。完成只用 `--success` 绿勾一次。卡住降亮度，不红核。

### 尺寸

- HUD 主核 152px（手机约 112px）→ 八态，这是说话对象
- 工人会话顶栏若保留入口 18px → 超级态
- 不再用对话气泡旁的 28px 脸作为首页

### 八态 → 三超级态

- idle ← idle、done（播完）
- active ← listen、think、work、queue
- needs_you ← ask、stuck

几何（关动画也要能认）：idle 缺口向右；listen 缺口朝用户气泡；think 双弧相对；work 卫星转；queue 停在 2 点；done 绿勾无缺口；ask 问号钩；stuck 缺口朝下。

多任务时管家只一张脸，优先级：

`ask > stuck > work > queue > listen > think > idle`

`done` 只播约 1 秒再回优先级结果。卡片左上 12px 色点表示该工人，不是第二张脸。

### 动效预算（仅管家圆徽、管家卡、开场）

- 曲线：`cubic-bezier(0.22, 1, 0.36, 1)`
- 开场：下浮 8px / 320ms，轨道晚 200ms 才转，只一次
- 发送：`idle → listen → think` 各 240ms → 出「收到，我来安排。」→ `work` + 卡每张错开 60ms
- 完成：绿勾 400ms + 复原 600ms，可复用现网成果勾的 0.5s scale
- 需你：2s 轻横移呼吸（对齐侧栏「需你回答」）
- `prefers-reduced-motion`：停在几何帧

禁止：粒子、霓虹拖尾、紫洗底、金/红、工人过程区轨道、每条工人消息播动画。

## 6. 界面（唯一版）

左右两栏，不要工作台三栏会话列表。

**左 · 沟通**

- 大圆徽就是贾维斯。只显示他当前一句 + 你刚说的一行。不是聊天记录。
- 默认打字：两行输入，可点回形针或拖入附件。回车发送，换行用 Shift+回车。
- **实时对话**是圆徽下方的独立按钮。点开后可选手头光核，或音频震动折线（更像贾维斯）。扬声器可关。
- 打字框始终在。实时对话时仍可打字打断。

**右 · 手头**

- 分组：需要你 → 进行中 → 排队 → 计划 → 刚搞定
- **进行中**：正在干什么、已齐几份、进度条、可暂停。你不用守着。
- **需要你**：缺额度、预览损坏、外发待允许。外发必须你点允许，不会偷偷发出去。
- **刚搞定**：缩略预览 + 文件条。可点或说「打开 / 保存 / 分享 / 发给谁」。打开在栏底展开预览；分享只备好链接；发送先问再发。
- 说任务名时，对应卡片会亮一下。说「收起」关掉预览。
- 排队推进、进度更新由他完成。不是文件夹树，不是聊天记录。

手机：上圆徽下手头。

### 实时语音（产品规则）

| 模式 | 怎么用 | 界面 |
|------|--------|------|
| 实时对话 | 圆徽下按钮，对着他说 | 电蓝「正在听」· 结束对话 |
| 扬声器 | 实时对话时旁钮 | 默开，可关 |
| 打断 | 再说话或打字 | 只停他说话 |

实现阶段：浏览器 Speech 可先落地；低延迟全双工再上 WebRTC。不要把语音做成又一条对话流。

## 7. 权限与执行（实现阶段，Demo 只演）

自动：开/续工人、能力锁到工人、入队、引擎补齐、查进度、非外发定时。

必问：缺 Key、权限、贵意图冲突、外发/群发/删云端。问完必须能推进。

禁止：subagent 写成果；管家自己落盘当交付；管家成果契约；跳过「需要你处理」。

「再出个 HTML」打到**已有工人**上追加，不在管家加槽。

扣量：工人走现有排队与扣次。查进度幂等。管家说话是一次短 turn，无契约。

完成权威：验收通过且证书 complete。不用本机「任务完成」勾。

提醒（实现时）：Push 增加搞定 / 失败 / 需你 / 计划跑完。你在工人里时只动圆徽。

接线（确认后再做）：`POST /api/saas/jarvis/delegate`；定时带能力上下文；管家工具仅管家会话可调。
