# 市场洞察与趋势

> Executive Summary (EN): Marketing teams face content throughput gaps, GEO disruption, and multimodal demand. Agent workflows that deliver project files—not chat snippets—are the next buying cycle. Nova targets this vertical rather than general-purpose agents.

---

## 1. 宏观趋势（2025–2026）

### 1.1 内容产能缺口持续扩大

- 品牌方要求**更多渠道、更短周期、更多模态**（图文 / 短视频 / 落地页 / 邮件）
- 人力编制未同比增长 → **AI 辅助生产**从「尝鲜」变为「编制外产能」
- 采购关注点从「能不能写」转向「能不能**交付可验收文件**」

### 1.2 GEO / AEO 重塑获客路径

- 用户越来越多通过 **AI 搜索 / 对话引擎**获取品牌信息
- 传统 SEO 之外新增 **生成式引擎可见度（GEO）** 优化需求
- 营销团队需要：审计 → 关键词与验证问句 → 可引用内容 → 监测闭环

**Nova 对应**：飞轮各阶段 AI 搜索 Pill、GEO 轻量/标准/全案模板、`pd-geo` 等能力包。

### 1.3 Agent 工作流从 Demo 进入采购清单

- 企业不再满足于 Chat UI，需要 **项目空间、记忆连续、工具调用、成果路径**
- 通用 Agent 平台（大厂）覆盖广但**垂直编排弱**
- 垂直 SaaS（营销创意）有机会以 **模板 + 飞轮 + 技能规模** 建立粘性

### 1.4 多模态成本波动

- Token、生图、生视频价格随供应商策略波动
- 平台方若全额补贴算力不可持续 → **订阅 + 积分双轨**成为行业共识
- **智能路由**成为 B 端卖点（省成本且可计量）

## 2. 目标品类机会

| 品类 | 市场状态 | Nova 机会 |
|------|----------|-----------|
| 通用 AI 聊天 | 红海、大厂主导 | 不正面竞争 |
| 营销自动化 MA | 成熟但偏规则编排 | 用自然语言 + Agent 降低配置成本 |
| 设计工具（Canva 类） | 强视觉、弱策略与调研 | Nova 补「策略→创意→发布」链 |
| 内容 AI（Jasper 类） | 强文案、弱项目与文件 | Nova 补「项目交付 + 飞轮」 |
| 国内营销云 | 重投放与 CRM | Nova 补「创意生产 + GEO」 |

---

## 3. 客户需求演变

```
阶段 1：试用 ChatGPT 写文案
阶段 2：发现交付散、无法验收、无法复用
阶段 3：寻找「项目型」平台 + 行业模板
阶段 4：要求企业隔离、用量可见、可私有部署
```

Nova 产品节奏对齐阶段 3–4。

---

## 4. 区域与语言

- **中文市场**：社媒矩阵（小红书等）、国内模型（通义、火山）、合规与备案
- **全球模型**：GPT / Claude / Gemini 满足出海与英文物料
- Nova **工作语言注入**：UI 切换语言 → 助手过程叙述同语言（已落地）

---

## 5. 市场叙事禁区

- 不编造「已服务 XX 家世界 500 强」（无实据则标待补充）
- 不承诺通用 Agent「替代全体员工」
- 不贬低竞品具体产品（用场景差异代替人身攻击）
