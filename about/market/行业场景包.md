# 行业场景包

> Executive Summary (EN): Five vertical playbooks—brand marketing, growth, MCN/agency, education, and government/enterprise comms—with recommended templates, flywheel stages, and talk tracks.

---

## 包 1：品牌市场（消费品 / 互联网）

**痛点**：Campaign 多、渠道杂、GEO 新课题、物料版本乱。

| 推荐模板 | 复杂度 |
|----------|--------|
| 品牌 Campaign 全案 | 全案 |
| 新品上市 | 全案 |
| AI 可见度快检 | 轻量 |
| 内容飞轮 | 标准 |

**飞轮重点**：1 调研 → 2 策略 → 3 创意 → 6 监测（GEO）

**话术**：「一季度 Campaign 从简报到监测报告，同一个 Nova 项目里完成。」

---

## 包 2：增长团队（B2B SaaS）

**痛点**：线索要内容喂养；MQL 转化素材产出慢。

| 推荐模板 | 复杂度 |
|----------|--------|
| SaaS 增长全案 | 全案 |
| 落地页获客 | 标准 |
| 竞品对比落地页 | 轻量 |
| 邮件 / B2B 拓客（能力组合） | 触达阶段 |

**飞轮重点**：1 调研（ICP）→ 3 创意（落地页）→ 4 触达 → 5 发布

**话术**：「增长同事不用等设计排期，先出可 A/B 的落地页草稿。」

---

## 包 3：广告 / MCN 工作室

**痛点**：比稿急、人手紧、客户要看得见的东西。

| 推荐模板 | 复杂度 |
|----------|--------|
| 竞品对比落地页 | 轻量 |
| 小红书爆款 | 标准 |
| 社媒矩阵 | 标准 |
| 大纲→PPT→炫酷 HTML 视频 | 全案 |

**飞轮重点**：1 竞品 → 3 创意 → 4 触达

**话术**：「48 小时比稿包：策略 md + 对比页 html + 主视觉方向。」

---

## 包 4：教育教研

**痛点**：通用 AI 不贴合学段与学术规范。

| 推荐入口 | 说明 |
|----------|------|
| 教育学习 Tab | 学前～学术研究 |
| Hermes Edu 技能包 | 同步 vendor 技能 |
| 办公模板（会议→PPT） | 校内汇报 |

**隔离原则**：教育 Tab 与营销飞轮分开，避免 K12 用户误入营销能力。

**话术**：「备课与学术写作有独立分类，不和投放技能混在一起。」

---

## 包 5：政企宣传 / 大型国企市场

**痛点**：合规、可审计、可私有部署、数据不出域。

| 推荐形态 | 说明 |
|----------|------|
| 私有部署 SaaS | 阿里云 Docker / 内网 |
| 单机版 + 内网模型 | 极高敏场景 |
| 企业安全亮点 | 租户、JWT、用量审计 |

**飞轮重点**：按宣传周期选用标准模板，弱化境外模型依赖（可配置国产池）。

**话术**：「支持私有化安装，项目和文件在贵司边界内，用量可审计。」

**销售专册**：[私有化与企业政务销售手册](../sales/私有化与企业政务销售手册.md)
