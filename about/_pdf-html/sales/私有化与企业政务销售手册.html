第三章：破冰与首次拜访

3.1 政企破冰原则

  1. 先合规后效率：第一句对齐「数据与文件在贵单位边界内」，再讲产能。
  2. 先听采购路径：直签还是招标，决定您准备材料深度。
  3. IT 与业务分开约：同天两场，各 30 分钟，避免业务讲技术、技术听营销。
  4. 用对方语汇：「宣传周期」「口径」「融媒体」「台账」而非纯互联网黑话。

3.2 场景话术

拜访宣传部门

[领导/科室] 您好。我们服务过多家宣传口单位，把调研简报、活动页面、监测汇总收在同一项目空间，对话里能点开验收，方便台账和迎检材料整理。想了解一下贵单位今年宣传数字化是偏内网自建还是托管？我们可按边界出方案摘要。

首次对接信息中心

我们提供 Docker 私有化交付：数据目录、数据库、配置与业务数据分离，升级只换镜像不覆盖现有数据和 .env。方便约 30 分钟对齐贵司网络分区、数据库规范和账号对接方式吗？

集成商合作

Nova 定位营销创意生产中台：飞轮六阶段、400+ 能力、近 30 条流程模板，可嵌入贵司总集方案。我们负责创作引擎与私有包交付，界面与 SSO 可按项目联调，验收以可预览成果文件为准。

领导简短汇报（1 页纸口头版）

Nova Ai-Studio 是智能体创作平台，帮助宣传口用自然语言完成整档项目交付；支持私有化安装，文件不出域；内置国产模型池可选；可按单位宣传周期配置模板与技能包。

第四章：交付形态怎么选

4.1 三种形态对照

形态适用优点注意
私有部署 SaaS企业/政府内网，要多用户与后台租户隔离、用量审计、统一升级需 PG、Redis、运维配合
单机版 + 内网极高敏、单人/少数人、要强本地编辑数据路径直观、文件完整 CRUD缺多租户运营后台
混合宣传口 SaaS + 涉密环节单机分场景隔离架构与商务需双合同清晰

详见 单机版与 SaaS 对照。

4.2 选型决策树（销售口头版）

数据能否上公网？
  ├─ 否 → 私有部署 SaaS（首选）或 单机版
  └─ 是但要强审计 → 专属 ECS 私有实例

是否要团队席位 + 用量报表？
  ├─ 是 → 私有 SaaS
  └─ 否 → 单机版试点

是否要定制技能 / 单位模板？
  └─ 是 → 企业年包 + 定制实施费（见第六章）

4.3 政企常见答法

客户问建议答法
「能不能完全离线？」可内网部署；模型推理需讨论是否允许调用内网大模型 API 或本地推理资源。
「能不能只用国产模型？」模型池可配置通义等国产供应商为主，按单位安全要求裁剪境外模型。
「升级会不会丢数据？」升级脚本只换程序镜像，不覆盖数据目录与线上配置。
「和通用聊天 AI 区别？」我们交付项目文件夹里的可验收文件，不是单次问答。

第五章：安全与合规销售叙事

5.1 四层「院子」故事（对 IT）

层一句话
租户每单位/用户独立院子，非大杂院
文件云端枢纽路径校验，防跨租户
工具权限白名单，非对话里恐吓式报错
用量后台可审计谁消耗多少算力

展开见 安全白皮书。

5.2 对宣传负责人的说法

  • 成果可预览、可下载、可定位文件夹——方便迎检与台账
  • 错误温和提示，不红屏中断——避免现场演示尴尬
  • 长任务自动恢复，不断档——适合活动前夕赶工

5.3 诚实边界（必说，建立信任）

话题对外口径
等保 / 分保按部署架构配合测评；不预承诺未获认证等级
内容安全生成内容须单位审核；平台可提供策略配置（按项目推进）
高强度代码执行建议私有部署 + 网络隔离；公网 SaaS 持续硬化
境外模型政企项目默认推荐国产池；境外模型需书面审批

5.4 政企 FAQ 速答

Q：数据存在哪？

A：私有部署时，租户项目与文件在贵司 DATA_ROOT 指定目录；控制库在贵司 PostgreSQL。

Q：默认管理员密码？

A：首装后必须修改；交付 checklist 写入验收项。

Q：能否对接统一身份认证？

A：企业项目可谈 SSO/LDAP 集成（按合同实施范围）。

Q：审计日志能否导出？

A：后台用量统计与 AI 用量大盘；更细审计按定制需求评估。

第六章：定制范围与商务

6.1 定制层级（报价必分项）

层级内容典型周期
L1 配置型模型池、能力开关、套餐、品牌 Logo 文案1–2 周
L2 模板/技能包单位宣传模板、行业流程模板、能力目录裁剪2–6 周
L3 集成型SSO、OA/融媒体系统对接、对象存储按接口评估
L4 专属功能新技能开发、审批流、内容审核模块项目制报价

原则：先卖标准私有包（L1），再增量卖 L2–L4；勿把 L4 当标配口头赠送。

6.2 推荐商务结构

收费项说明
软件授权 / 年付私有实例 + 席位 + 维保
实施费安装、调优、培训、验收
定制开发费L2–L4 单独立项
算力客户自备 Key 或代采积分包
续保年费率 15%–20%（参考，按公司政策）

套餐框架见 商业模式与套餐、定价逻辑。

6.3 报价话术

「私有化我们按 三部分 报：① 平台年授权与席位 ② 一次性实施与培训 ③ 可选定制包。算力可以走贵司已有大模型账号，我们收平台与路由服务费，避免算力价差扯皮。」

6.4 合同验收建议（写入附件）

  • [ ] 管理员改密、备份策略文档交付
  • [ ] 培训 ≥1 场（宣传口 + IT 各一场更佳）

7.2 政企 POC 设计（建议 2–4 周）

项建议
场景选单位真实宣传周期：如「主题教育素材包」「年度形象片脚本+页面」

第九章：异议处理（政企专篇）

异议应答
「我们已有 XX 大模型平台」Nova 补宣传飞轮与成果验收层，可并行而非替换
