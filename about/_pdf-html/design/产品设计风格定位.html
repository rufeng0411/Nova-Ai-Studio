产品设计风格定位

产品设计风格定位

Executive Summary (EN): Nova UI follows graphite premium minimalism—professional creative platform, not flashy consumer apps. Tokenized radii, muted accents, Sketch-inspired admin.

设计目标

极简高级 · 专业 AI 创作平台

  • 服务营销、创作、企业用户——不是消费级娱乐 UI
  • 深浅色均避免纯黑纯白与高饱和强调色
  • 高级感来自分层灰度、留白、克制动效，非装饰美术

视觉语言

元素规范
浅色主题石墨高级灰分层（graphite premium）
深色主题冷色过渡、侧栏 bg-sidebar
圆角0.625rem 体系
图标按钮Token 化，现代化线条
滚动条细化、低对比
Pill 导航L2 实底选中；L3 仅字重与主色

关键界面气质

界面气质
登录 Hero轮播八大亮点，工业感 + 品牌 Logo
主工作区对话为中心，成果可触达
能力中心信息密度适中，四列卡片，悬停浮层
后台 Admin经典 Sketch 仪表盘，数据优先
手机版Logo 常驻 + 菜单；子页与桌面能力对齐

品牌与 UI 关系

  • 用户可见统一为 Nova Ai-Studio
  • Logo：主界面图标；登录可有 wordmark
  • 产品介绍：Logo 弹窗 / 手机「我的」子页共用 ProductInfoOverview

反面案例（避免）

  • 彩虹渐变、游戏化勋章
  • 满屏大红报错（改用温和灰提示）
  • 能力卡片花哨插画抢戏
