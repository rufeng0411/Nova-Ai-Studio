Nova Ai-Studio 品牌手册

Executive Summary (EN): Nova Ai-Studio is the customer-facing brand for our agent creative platform. Use "Nova Ai-Studio 2.0" in all public materials.

1. 品牌名称

场景写法
正式全称Nova Ai-Studio
带版本Nova Ai Studio 2.0
中文副标题Nova Ai Studio 2.0 智能体创作平台
简称（口语）Nova、Nova 创作平台

对外材料统一使用 Nova 品牌，不出现第三方或历史项目名称。

2. 品牌承诺与调性

品牌承诺：用对话完成复杂项目——从一句需求到可交付成果。

调性关键词：

  • 极简高级（石墨灰分层，非纯黑纯白）
  • 专业创作平台（非玩具、非花哨美术）
  • 可信、可部署（企业 SaaS 叙事）
  • 中文优先、全球模型（通义、GPT、Claude、Gemini 等一池统管）

3. 标语体系

层级中文英文
主标语以对话驱动的 AI 工作台，自然语言完成复杂任务。A conversation-driven AI workspace for complex work in natural language.
副标语（垂直）AI 营销创意生产平台 — 飞轮闭环、400+ 能力、企业可部署AI marketing creative production — flywheel, 400+ capabilities, enterprise-ready
行动号召不知道怎么开始？选一条流程模板，一键开跑。Not sure where to start? Pick a workflow template and run.

4. Logo 与视觉资产

权威清单：config/nova-brand.manifest.json

资产说明用途
Logo 图标见 config/nova-brand.manifest.json侧栏、Loading、登录 Hero
Wordmark（深色）Nova 深色 Wordmark后台管理顶栏（高度 28px）
Wordmark（浅色）Nova 浅色 Wordmark浅色主题场景
Favicon见 manifest浏览器标签

用法规则：

  • 主界面侧栏：仅 Logo 图标，不展示英文 wordmark 图片
  • 登录页：可保留 wordmark + Hero 轮播
  • 禁止拉伸、改色、加描边破坏识别度
  • 重生成资产：npm run brand:assets；校验：npm run brand:check

5. 色彩与界面风格

  • 浅色主题：石墨高级灰分层（graphite premium），避免高饱和强调色
  • 圆角：0.625rem 体系化
  • 能力中心：L1 分段 Tab → L2 步进 Pill → L3 纯文字子类
  • 后台管理：经典 Sketch 风格仪表盘（od-dashboard 设计基因）

详见 产品设计风格定位。

6. 对外话术禁区

不要做应该做
「我们是某某开源工具的套壳」「Nova Ai-Studio 是企业级智能体创作平台」
罗列 877 条 skill 精确数说「400+ 即用能力」
承诺未上线的 SLA / 客户名标「待补充」或引用已验收能力
恐吓式安全文案（大红报错）温和提示 + 企业级隔离叙事

7. 品牌校验

发布或合并大版本前须执行：

npm run brand:check

失败按 docs/nova-brand-guard.md 恢复，确保 Nova 品牌资产完整一致。
