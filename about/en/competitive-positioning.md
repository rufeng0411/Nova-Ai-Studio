# Competitive Positioning (EN)

## One-line position

**Nova = AI marketing creative production platform** (project delivery + flywheel + 400+ capabilities + enterprise SaaS)—not a general-purpose chat agent.

## Comparison matrix

| Type | Strengths | Gaps vs Nova | Nova talk track |
|------|-----------|--------------|-----------------|
| General chat (ChatGPT, etc.) | Ubiquitous, strong Q&A | No project space, no flywheel, weak file acceptance | "We deliver campaign folders, not chat logs." |
| Developer agents (Claude Code, etc.) | Code & reasoning | Weak marketing, GEO, design systems | "Flywheel and templates for marketers out of the box." |
| Copy AI (Jasper, etc.) | Copy templates | Weak research, multimodal, China social | "Research through publish on one platform." |
| Design tools (Canva, Figma AI) | Fast visuals | Weak strategy, GEO, monitoring | "150 design systems plus upstream strategy." |
| Marketing clouds (HubSpot, etc.) | CRM, attribution | Creative agent orchestration not core | "Creative production layer; export files to your stack." |
| Workflow builders (Coze, Dify) | Flexible | Needs engineers; few marketing templates | "Marketers click templates—no node wiring." |

## Strategy

**Avoid**: generic Q&A leaderboard, raw coding-agent mindshare.

**Attack**:

1. End-to-end **marketing file delivery**  
2. **GEO** visibility in the AI-search era  
3. China-friendly multimodal (Qwen, Volcano, social matrix skills)  
4. **Deployable enterprise** story (tenant, cloud, usage, private)
