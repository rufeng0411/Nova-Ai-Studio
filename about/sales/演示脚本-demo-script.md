# 演示脚本（15 分钟 Demo Script）

> 演示前请对照 [销售指导手册](销售指导手册.md) 确认客户认知层级与行业包；本脚本仅覆盖现场操作步骤。

---

## 准备

| 项 | 要求 |
|----|------|
| 环境 | `npm run dev:saas` 或客户私有实例 |
| 账号 | admin 或演示租户（公网前勿用默认弱密展示）|
| 浏览器 | Chrome / Edge，宽屏 ≥1280px |
| 备选 | 若网络慢，预跑一条模板留下成果文件 |

---

## 分钟级脚本

### 0:00–2:00 开场与品牌

**说**：「Nova Ai-Studio 是一句话交付整个项目的 AI 营销创作平台，不是聊天窗口。」

**做**：
1. 打开登录页 → 指出 Hero 轮播八大亮点
2. 登录主界面
3. 点击 Logo → 产品弹窗（400+、飞轮、模板、安全统计条）

**要点**：主标语 + 垂直定位「AI 营销创意生产平台」

---

### 2:00–5:00 流程模板（不知道怎么开始）

**说**：「新人最怕空白页。我们有近 30 条模板，从竞品快览到品牌全案。」

**做**：
1. 输入区「模板」或侧栏流程模板入口
2. 选 **「竞品与口碑快览」** 或 **「AI 可见度快检」**（轻量、2 步、快）
3. 点 **试一下** → 新建对话，预填提示词
4. 发送一句补充：「我们品牌是 __，竞品是 __」（按客户行业改）

**要点**：模板 = 编排好的对话起点，不是 PPT 说明

---

### 5:00–9:00 能力中心与飞轮

**说**：「400 多项能力按营销六阶段组织，点卡片就能试。」

**做**：
1. 侧栏进入能力中心
2. 停留 **营销飞轮** Tab
3. L2 切到 **调研洞察** 或 **监测复盘**
4. 点 1 张卡片「试一下」
5. 提一句 **AI 搜索 / GEO** Pill

**要点**：五 Tab（办公/创作/开发/教育）一笔带过，聚焦客户行业

---

### 9:00–12:00 成果交付（关键差异）

**说**：「成果是文件，不是一段话。对话里直接点开验收。」

**做**：
1. 若有已生成 md/html → 点击成果卡片 **预览**
2. 演示弹窗：Markdown / PDF / 图片 之一
3. 指 **下载**、**在文件夹中打开**（若有）
4. 若无成果：打开历史项目展示预跑文件

**要点**：对比「复制 ChatGPT 文字到 Word」

---

### 12:00–14:00 企业叙事（SaaS 客户）

**说**：「团队版租户隔离、文件全云端、后台可看 AI 用量。」

**做**：
1. （可选）后台 Admin → 运营/用量一眼
2. 设置页提 **用量** 非技术细节
3. 一句 **智能路由省 Token**

**单机客户**：改讲本地完整编辑 + 可选私有部署

---

### 14:00–15:00 收尾与 POC

**说**：「建议 2 周 POC：选一条贵司真实模板，验收 2 个文件；我们给积分包。」

**给材料**：
- 产品总览 one-pager
- 四列 PDF（`npm run brand:product-brief-pdf`）

**问**：「您更关心产能、GEO 还是私有化？」→ 约下次行业场景包深聊

---

## 行业变体（替换模板步骤）

| 行业 | 模板替换 |
|------|----------|
| 品牌 | 品牌 Campaign 全案（讲全案，可不完全跑完）|
| B2B | SaaS 增长全案 / 落地页获客 |
| 工作室 | 小红书爆款 / 竞品对比落地页 |
| 教育 | 教育 Tab + 会议→PPT |

---

## 演示禁忌

- 不要现场改模型 Key（用池已配环境）
- 不要承诺单次生成 100% 完美
- 不要展示内部 UUID 文件夹或工程路径
