# 私有化与企业政务销售手册

> **适用对象**：政企大客户销售、售前架构师、交付项目经理  
> **版本**：2026-06 · 与 [00-口径与更新](../00-口径与更新.md) 数字一致  
> **通用销售流程**：获客、破冰、认知分层见 [销售指导手册](销售指导手册.md)

---

## 本手册定位

面向**私有化部署、内网交付、定制开发**诉求的企业与政府客户，回答四类核心问题：

1. **谁该推私有方案？**（客户画像与线索信号）
2. **怎么进得去门？**（政企破冰与关系路径）
3. **怎么讲清楚？**（安全、部署、定制边界）
4. **怎么收钱、怎么交付？**（商务结构、POC、实施节奏）

**不适用**：纯个人 Pro、10 人以内互联网小团队的标准 SaaS 订阅——请用通用 [销售指导手册](销售指导手册.md)。

## 第一章：目标客户画像

### 1.1 优先跟进的政企 ICP

| 维度 | 强信号（A 级） | 培育信号（B 级） |
|------|----------------|------------------|
| **组织** | 央国企、部委/厅局宣传口、省级国企市场部 | 地市国企、事业单位宣传中心 |
| **规模** | 市场/品牌/融媒体中心 ≥15 人 | 5–15 人但有年度宣传预算 |
| **合规** | 明确要求数据不出域、等保/分保语境 | 「不能用境外模型」「要内网」 |
| **采购** | 年度信息化/宣传数字化预算已立项 | 领导口头要求「搞 AI 创作平台」 |
| **场景** | 周期性政务宣传、国企品牌传播、重大活动物料 | 零星海报、单次活动 |

### 1.2 典型角色与诉求

| 角色 | 诉求 | 您要递什么 |
|------|------|------------|
| **宣传部门负责人** | 产能、口径统一、可验收成果 | 飞轮 + 模板 + 成果预览 |
| **信息中心 / IT** | 部署形态、账号、审计、升级 | 部署叙事 + 安全白皮书 |
| **采购 / 法务** | 合同范围、验收标准、维保 | POC 附件 + 报价分项 |
| **分管领导** | 政治安全、不出事、可汇报 | 国产模型池 + 私有边界一句 |

用户画像延伸见 [用户画像 § 政企向](../product/用户画像与场景.md)；行业包见 [行业场景包 §5](../market/行业场景包.md#包-5政企宣传--大型国企市场)。

### 1.3 不适合强推私有的情况

| 信号 | 建议 |
|------|------|
| 仅 1–2 人试用、无预算 | 引导标准 SaaS 或搁置 |
| 只要「买个 ChatGPT 账号」 | 澄清项目交付差异，不匹配则礼貌退出 |
| 要求源码全交付且无限运维 | 单独商务评估，勿口头承诺 |
| 无 IT 配合、无服务器资源 | 先解决基础设施再谈私有 |

- [ ] 数据是否必须在内网？

- [ ] 模型是否要求国产为主（通义、文心等）？
- [ ] 采购形式：直签 / 招标 / 集成商总包？
- [ ] 定制范围：仅配置 / 技能+模板 / 界面品牌 / 对接 OA？

| 级别 | 条件 | 销售动作 |
|------|------|----------|

## 第三章：破冰与首次拜访

### 3.1 政企破冰原则

1. **先合规后效率**：第一句对齐「数据与文件在贵单位边界内」，再讲产能。
2. **先听采购路径**：直签还是招标，决定您准备材料深度。
3. **IT 与业务分开约**：同天两场，各 30 分钟，避免业务讲技术、技术听营销。
4. **用对方语汇**：「宣传周期」「口径」「融媒体」「台账」而非纯互联网黑话。

### 3.2 场景话术

#### 拜访宣传部门

> [领导/科室] 您好。我们服务过多家**宣传口**单位，把调研简报、活动页面、监测汇总收在**同一项目空间**，对话里能点开验收，方便台账和迎检材料整理。想了解一下贵单位今年宣传数字化是偏**内网自建**还是**托管**？我们可按边界出方案摘要。

#### 首次对接信息中心

> 我们提供 **Docker 私有化交付**：数据目录、数据库、配置与业务数据分离，**升级只换镜像不覆盖**现有数据和 `.env`。方便约 30 分钟对齐贵司网络分区、数据库规范和账号对接方式吗？

#### 集成商合作

> Nova 定位**营销创意生产中台**：飞轮六阶段、400+ 能力、近 30 条流程模板，可嵌入贵司总集方案。我们负责创作引擎与私有包交付，界面与 SSO 可按项目联调，**验收以可预览成果文件为准**。

#### 领导简短汇报（1 页纸口头版）

> Nova Ai-Studio 是**智能体创作平台**，帮助宣传口用自然语言完成整档项目交付；支持**私有化安装**，文件不出域；内置**国产模型池**可选；可按单位宣传周期配置模板与技能包。

## 第四章：交付形态怎么选

### 4.1 三种形态对照

| 形态 | 适用 | 优点 | 注意 |
|------|------|------|------|
| **私有部署 SaaS** | 企业/政府内网，要多用户与后台 | 租户隔离、用量审计、统一升级 | 需 PG、Redis、运维配合 |
| **单机版 + 内网** | 极高敏、单人/少数人、要强本地编辑 | 数据路径直观、文件完整 CRUD | 缺多租户运营后台 |
| **混合** | 宣传口 SaaS + 涉密环节单机 | 分场景隔离 | 架构与商务需双合同清晰 |

详见 [单机版与 SaaS 对照](../product/单机版与SaaS版对照.md)。

### 4.2 选型决策树（销售口头版）

```
数据能否上公网？
  ├─ 否 → 私有部署 SaaS（首选）或 单机版
  └─ 是但要强审计 → 专属 ECS 私有实例

是否要团队席位 + 用量报表？
  ├─ 是 → 私有 SaaS
  └─ 否 → 单机版试点

是否要定制技能 / 单位模板？
  └─ 是 → 企业年包 + 定制实施费（见第六章）
```

### 4.3 政企常见答法

| 客户问 | 建议答法 |
|--------|----------|
| 「能不能完全离线？」 | 可内网部署；模型推理需讨论是否允许调用内网大模型 API 或本地推理资源。 |
| 「能不能只用国产模型？」 | 模型池可配置通义等国产供应商为主，按单位安全要求裁剪境外模型。 |
| 「升级会不会丢数据？」 | 升级脚本只换程序镜像，不覆盖数据目录与线上配置。 |
| 「和通用聊天 AI 区别？」 | 我们交付**项目文件夹里的可验收文件**，不是单次问答。 |

## 第五章：安全与合规销售叙事

### 5.1 四层「院子」故事（对 IT）

| 层 | 一句话 |
|----|--------|
| 租户 | 每单位/用户独立院子，非大杂院 |
| 文件 | 云端枢纽路径校验，防跨租户 |
| 工具 | 权限白名单，非对话里恐吓式报错 |
| 用量 | 后台可审计谁消耗多少算力 |

展开见 [安全白皮书](../trust/安全与信任白皮书-简版.md)。

### 5.2 对宣传负责人的说法

- 成果**可预览、可下载、可定位文件夹**——方便迎检与台账
- 错误**温和提示**，不红屏中断——避免现场演示尴尬
- 长任务**自动恢复**，不断档——适合活动前夕赶工

### 5.3 诚实边界（必说，建立信任）

| 话题 | 对外口径 |
|------|----------|
| 等保 / 分保 | 按部署架构配合测评；**不预承诺**未获认证等级 |
| 内容安全 | 生成内容须单位审核；平台可提供策略配置（按项目推进）|
| 高强度代码执行 | 建议私有部署 + 网络隔离；公网 SaaS 持续硬化 |
| 境外模型 | 政企项目默认推荐国产池；境外模型需书面审批 |

### 5.4 政企 FAQ 速答

**Q：数据存在哪？**  
A：私有部署时，租户项目与文件在贵司 `DATA_ROOT` 指定目录；控制库在贵司 PostgreSQL。

**Q：默认管理员密码？**  
A：首装后**必须**修改；交付 checklist 写入验收项。

**Q：能否对接统一身份认证？**  
A：企业项目可谈 SSO/LDAP 集成（按合同实施范围）。

**Q：审计日志能否导出？**  
A：后台用量统计与 AI 用量大盘；更细审计按定制需求评估。

## 第六章：定制范围与商务

### 6.1 定制层级（报价必分项）

| 层级 | 内容 | 典型周期 |
|------|------|----------|
| **L1 配置型** | 模型池、能力开关、套餐、品牌 Logo 文案 | 1–2 周 |
| **L2 模板/技能包** | 单位宣传模板、行业流程模板、能力目录裁剪 | 2–6 周 |
| **L3 集成型** | SSO、OA/融媒体系统对接、对象存储 | 按接口评估 |
| **L4 专属功能** | 新技能开发、审批流、内容审核模块 | 项目制报价 |

**原则**：先卖标准私有包（L1），再增量卖 L2–L4；**勿把 L4 当标配**口头赠送。

### 6.2 推荐商务结构

| 收费项 | 说明 |
|--------|------|
| **软件授权 / 年付** | 私有实例 + 席位 + 维保 |
| **实施费** | 安装、调优、培训、验收 |
| **定制开发费** | L2–L4 单独立项 |
| **算力** | 客户自备 Key 或代采积分包 |
| **续保** | 年费率 15%–20%（参考，按公司政策） |

套餐框架见 [商业模式与套餐](../business/商业模式与套餐.md)、[定价逻辑](../business/定价逻辑说明.md)。

### 6.3 报价话术

> 「私有化我们按 **三部分** 报：① 平台年授权与席位 ② 一次性实施与培训 ③ 可选定制包。算力可以走贵司已有大模型账号，我们收平台与路由服务费，避免算力价差扯皮。」

### 6.4 合同验收建议（写入附件）

- [ ] 私有环境安装成功，健康检查通过
- [ ] 指定模板跑通 ≥2 次，产出可预览文件
- [ ] 多用户不串项目（SaaS 私有）
- [ ] 管理员改密、备份策略文档交付
- [ ] 培训 ≥1 场（宣传口 + IT 各一场更佳）
- [ ] 定制项单独清单与签收

## 第七章：销售流程与 POC

### 7.1 政企七步流程

```mermaid
flowchart LR
  R[关系/招标线索] --> Q[需求与合规澄清]
  Q --> A[联合拜访 IT+业务]
  A --> S[方案摘要 1 页]
  S --> P[私有 POC]
  P --> B[招投标/商务]
  B --> D[实施交付]
  D --> E[验收+续保]
```

| 阶段 | 关键产出 |
|------|----------|
| 需求澄清 | 《数据边界确认单》勾选内网/模型/账号 |
| 方案摘要 | 形态选型 + 组件清单 + 报价区间 |
| 私有 POC | 客户 VPC 或厂商演示 ECS，**真实内网更接近成交** |
| 招投标 | 技术偏离表 + 验收标准对齐本手册 6.4 |
| 交付 | install → 培训 → 验收签字 |

### 7.2 政企 POC 设计（建议 2–4 周）

| 项 | 建议 |
|----|------|
| 场景 | 选单位真实宣传周期：如「主题教育素材包」「年度形象片脚本+页面」 |
| 模板 | 1 个轻量 + 1 个标准，覆盖飞轮 ≥3 阶段 |
| 用户 | 宣传 2 人 + IT 1 人旁观审计 |
| 成功标准 | ≥2 类可交付物（md/html/pdf）+ 用量报表截图 |
| 失败止损 | 第二周无 IT 配合则暂停，避免无限 POC |

演示操作见 [演示脚本](演示脚本-demo-script.md)；**政企专场**减少境外模型演示，预配国产池。

### 7.3 招投标常见评分点应对

| 评分维度 | Nova 可回应点 |
|----------|----------------|
| 技术方案 | 双轨架构、私有 Docker、PG 控制面 |
| 安全 | 租户隔离、JWT、路径校验、私有边界 |
| 易用 | 模板一键、成果预览、中文 UI |
| 售后 | 维保、升级不覆盖数据、培训 |
| 国产化 | 国产模型池、可内网部署 |
| 案例 | 仅列**已授权**案例，无则写「试点中」 |

## 第九章：异议处理（政企专篇）

| 异议 | 应答 |
|------|------|
| 「我们已有 XX 大模型平台」 | Nova 补**宣传飞轮与成果验收层**，可并行而非替换 |
| 「价格高于 SaaS 公有云」 | 私有卖的是**边界、审计、定制、维保**，不是席位低价 |

### 卡片 1 — 私有边界 30 秒
