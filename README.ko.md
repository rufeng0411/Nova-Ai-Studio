# Nova Ai-Studio

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md)

대화로 프로젝트 파일을 만드는 **AGPL 커뮤니티 에디션**(내 PC에서 돌리는 워크벤치). 전문은 [English README](README.md) · [简体中文](README.zh-CN.md).

```bash
cp .env.example .env
corepack enable
pnpm install
pnpm run dev
```

Vite URL → `/login` → `admin` + `SAAS_ADMIN_PASSWORD` → 작업대.
