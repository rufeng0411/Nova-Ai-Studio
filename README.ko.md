대화로 프로젝트 산출물을 만드는 기업용 AI Agent. 이 GitHub는 AGPL 개인 셀프호스트 판입니다. 전문은 [English README](README.md) · [简体中文](README.zh-CN.md).

```bash
cp .env.example .env
corepack enable
pnpm install
pnpm run dev
```

Vite URL → `/login` → `admin` + `SAAS_ADMIN_PASSWORD` → 작업대.
