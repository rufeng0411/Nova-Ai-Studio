会話でプロジェクト一式を渡す企業向け AI Agent。この GitHub は AGPL の個人セルフホスト版です。全文は [English README](README.md) と [简体中文](README.zh-CN.md)。

```bash
cp .env.example .env
corepack enable
pnpm install
pnpm run dev
```

Vite URL → `/login` → `admin` + `SAAS_ADMIN_PASSWORD` → 作業台。
