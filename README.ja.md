会話でファイル一式を渡す **AGPL コミュニティ版**（自分の PC で動かすワークベンチ）。全文は [English README](README.md) と [简体中文](README.zh-CN.md)。

```bash
cp .env.example .env
corepack enable
pnpm install
pnpm run dev
```

Vite URL → `/login` → `admin` + `SAAS_ADMIN_PASSWORD` → 作業台。
