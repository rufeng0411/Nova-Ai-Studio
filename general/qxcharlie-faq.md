# QXCHARLIE — 产品常见问题（FAQ）

## 1. QXCHARLIE 支持哪些平台和设备？

QXCHARLIE 目前支持 **Web 浏览器**（Chrome / Edge / Safari / Firefox 最新版）、**iOS 15+** 和 **Android 12+** 原生应用。数据通过云端实时同步，多端无缝衔接，切换设备无需额外操作。

## 2. 免费版和付费版有什么区别？

| 功能 | 免费版 | 付费版（月费 ¥29） |
|------|--------|-------------------|
| 核心功能 | ✅ 全部可用 | ✅ 全部可用 + 高级模板 |
| 存储空间 | 5 GB | 100 GB |
| 协作成员数 | 最多 3 人 | 不限人数 |
| 优先级客服 | ❌ | ✅ 专属通道 |
| API 调用额度 | 无 | 10 万次/月 |

## 3. 如何申请退款或取消订阅？

在 **设置 → 账号 → 订阅管理** 中随时取消自动续费，取消后当前计费周期仍可继续使用至到期日。如购买后 7 日内未使用超过 3 次，可提交工单申请全额退款，通常 1–3 个工作日原路退回。
