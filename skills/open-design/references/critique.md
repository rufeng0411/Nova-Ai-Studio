# 五维自评门禁

完成初稿后，按 1-5 分对以下维度打分。任一维度 < 3 分，必须修正后再交付。

1. 哲学一致性（Philosophy）  
   视觉风格是否真正匹配任务目标？

2. 信息层级（Hierarchy）  
   首要信息是否一眼可见？是否出现“全部都重要”？

3. 执行质量（Execution）  
   字号、行高、间距、对齐、对比度是否达标？

4. 场景具体性（Specificity）  
   文案、指标、模块是否贴合用户业务语境？

5. 克制与节奏（Restraint）  
   是否只保留 1-2 个真正有效的视觉亮点？

## 输出建议

- 简短列出每个维度得分与一句证据。
- 如果低分，先改再提交，不把“待改项”直接甩给用户。
