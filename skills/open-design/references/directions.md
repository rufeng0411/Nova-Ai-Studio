# 视觉方向库（迁移自 Open Design）

当用户未提供品牌系统时，从以下 5 个方向中选择。选中后将其 palette 与字体栈绑定为本次设计的默认基线。

## 1. Editorial / Monocle

- 关键词：杂志感、留白、克制、出版级排版
- 字体：衬线展示 + 无衬线正文
- 适用：品牌故事、内容型主页、报告封面

推荐 token（示意）：

```css
:root {
  --bg: oklch(98% 0.004 95);
  --surface: oklch(100% 0.002 95);
  --fg: oklch(20% 0.018 70);
  --muted: oklch(48% 0.012 70);
  --border: oklch(90% 0.006 95);
  --accent: oklch(52% 0.10 28);
}
```

## 2. Modern Minimal / Linear

- 关键词：软件感、精确、冷静、轻量层次
- 字体：系统无衬线为主
- 适用：SaaS、B2B 产品、控制台

```css
:root {
  --bg: oklch(99% 0.002 240);
  --surface: oklch(100% 0 0);
  --fg: oklch(18% 0.012 250);
  --muted: oklch(54% 0.012 250);
  --border: oklch(92% 0.005 250);
  --accent: oklch(58% 0.18 255);
}
```

## 3. Human / Approachable

- 关键词：友好、可亲、轻品牌感、消费级
- 字体：无衬线为主，层级清晰
- 适用：面向 C 端产品、教育、社区、内容平台

## 4. Tech Utility

- 关键词：信息密度、数据优先、工程工具、可观测性
- 字体：无衬线 + 等宽数字
- 适用：仪表盘、运维平台、分析后台

## 5. Brutalist / Experimental

- 关键词：冲击、实验、强烈对比、结构感
- 字体：大字号展示 + 等宽正文
- 适用：活动页、创意品牌、实验项目

## 使用规则

- 一次只选一个主方向。
- 用户有品牌规范时，方向库只作为补充，不覆盖品牌硬约束。
- 方向选定后，accent 使用不超过 2 个高权重区域。
