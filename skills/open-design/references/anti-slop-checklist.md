# Anti-Slop 检查清单

交付前逐条检查，避免“AI 味”。

## P0（必须通过）

- [ ] 视觉方向明确且一致（不是混搭拼盘）。
- [ ] 文字与场景具体，不出现“Feature 1/2/3”占位文案。
- [ ] 无伪造数据（如随意写 99.9%、10x）。
- [ ] 主色与强调色有节制（强调色高权重场景 <= 2）。
- [ ] 页面结构可读，首屏层级明确。

## P1（建议通过）

- [ ] 字体搭配有角色分工（display/body）。
- [ ] 组件边界统一（圆角、边框、阴影风格一致）。
- [ ] 视觉噪音受控（不过度渐变、不过度图标、不过度动画）。

## 黑名单（默认禁用）

- 紫色渐变大背景 + 白卡片的通用 AI 模板风
- 每个标题都配 emoji 图标
- 暖棕/米桃色整页底色（除非品牌证据明确要求）
- 无意义装饰线条/图形堆叠
