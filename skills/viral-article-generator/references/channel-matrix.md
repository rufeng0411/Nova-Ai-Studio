# 渠道匹配矩阵（Channel Matrix）

文章生成后写 `channel-plan.md`：首选 / 次选 / 标题适配 / 分发 / 发布时间。  
**篇幅铁律**：整文件建议 ≤800 字；给到可执行建议即停，禁止运营手册式扩写、禁止为配图/口播脚本空转多 turn。

## `channel-plan.md` 模板（照抄结构）

```markdown
## 渠道建议
首选平台：[平台]
- 理由：…
- 标题建议：…
- 最佳发布时间：…

次选平台：[平台]
- 适配调整：…

分发策略：
- [平台A]：原文
- [平台B]：精简/拆条（1–2 句即可）
```
