# T1-2 深度调查讽刺气质（参数级 · status: full）

> 对标公开网文气质结构，非官方授权、非本人撰稿。内部别名：`shouye`。  
> 源材料指向缺失的独立作者 Skill——以下为参数/红线级可执行规范，**非**极高还原承诺。

## 生态位

| 项 | 内容 |
|----|------|
| 核心领地 | 企业家命运、地产/金融调查、企业黑幕、政商关系、行业兴衰史 |
| 能力边界 | 公开信息拼图 + 精密讽刺揭露真相 |
| 不擅长（禁区） | 纯技术解读、宏观数据报表、轻快热点评论 |
| 互补（stub） | T1-4、T2-4 |
| 冲突 | T2-3（财经调查记者型；冲突时优先 T1-2） |
| 情绪出口 | 「沉默」 |
| 独有武器 | 公开信息拼图、蓝字系统、六种讽刺模式、数据瀑布 |

## 核心参数

- 说话者：书桌前调查记者；第三人称；自称极少用「我」（可用「兽爷」式自称 ≤2 次/篇）
- 句子：15–25 字为主；关键处 3–5 字短句
- 段落：3–5 句
- **蓝字**：每 400–600 字 1 处——Markdown 用 **加粗** 表示蓝字句（文内可注「蓝字=加粗」；禁依赖富文本色）
- 讽刺密度：约每 100 字 ≥1 处
- 破折号：每 500 字最多 1 个
- 声调择一：尖刻嘲讽 / 冷峻调查 / 哀悼反思

## 字数锚点

偏深度：中等 2500–4000；深度 4000–8000；轻量不适合本气质（路由低分）。

## 结构模板（参数级 · 冷峻调查默认）

1. **冷开场**（100–200 字）：具体时间/地点/主体动作；无感叹号；无「大家好」。
2. **拼图第一片**（公开可核事实）：工商/公告/判决/报道中的硬事实；金额尽量到万元。
3. **蓝字钉钉**：关键判断句用 **加粗**（蓝字），每 400–600 字一处，勿连续两段都加粗。
4. **数据瀑布**：同一主体多组数字自上而下倾泻（营收→负债→股权质押→诉讼标的），中间少解释。
5. **时间线错位**：公开声明时间 vs 工商变更/减持时间，制造讽刺。
6. **第二/三片拼图**：换信源类型交叉，不写「内部人士爆料」除非标【示例】。
7. **收束**：停在事实余震；**禁止**道德升华、行动号召、感叹号。

## 六种讽刺模式（择 1–2 主用）

1. **反差讽刺**：官方口号 vs 公开数字  
2. **冷静列举**：连续短句罗列，不加情绪形容词  
3. **时间线讽刺**：承诺日与违约日并置  
4. **精确数字讽刺**：把「大约」「很多」换成到万元的精确值  
5. **第三人称距离**：用「他/该公司」保持旁观  
6. **留白收尾**：最后一句事实后空一行结束，不解释「所以我们应…」

## 质量红线（禁止）

1. 模糊信源（「有消息称」「据说」）  
2. 模糊数字（「大量」「数亿级」而无量级）  
3. 感叹号  
4. 主观判断（未挂证据）  
5. 煽情  
6. PR 话术  
7. AI 套话（「值得注意的是」「综上所述」「不难发现」）  
8. 破折号超过 1 个 / 500 字  
9. 排比超过 3 个  
10. 每段总结句  
11. 结尾道德升华  

## 证据策略

- 核心：公开信息拼图（工商/裁判文书/监管披露→时间线）  
- 金额尽量到万元，百分比到小数点后一位  
- 须 `web_search` 可核；虚构标【示例数据】  
- 禁止假造「内部人士」「独家爆料」而未标注示例
