# 风格路由矩阵（Routing Matrix）

选题 6 维打分；每维 0–10；总分 /60。brief 输出 TOP3（含 stub 标注）；**自动主写只取 status=full 且分最高者**。

## 维度定义

| 维 | 含义 | 可选值 |
|----|------|--------|
| D1 领域 | 行业 | 财经 / 商业 / 消费 / 互联网 / 社会 / 科技 / 人物 / 政策 |
| D2 性质 | 内容性质 | 事件 / 趋势 / 人物 / 数据 / 争议 / 历史 / 方法论 |
| D3 证据 | 可用证据 | 公开数据 / 人物故事 / 调查报告 / 逻辑推演 / 历史资料 |
| D4 情绪 | 读者出口 | 愤怒讽刺 / 好奇震撼 / 共鸣温暖 / 认知升级 / 沉默反思 / 赋能行动 |
| D5 深度 | 篇幅 | 轻量 1500–2500 / 中等 2500–4000 / 深度 4000–8000 / 重磅 8000+ |
| D6 时效 | 时效 | 热点追踪 / 周期性 / 常青 |

## 打分刻度（统一）

| 落位 | 建议分 |
|------|--------|
| 高分偏好 | 8–10（默认 9） |
| 中分偏好 | 5–7（默认 6） |
| 低分 | 2–4（默认 3） |
| **禁区** | **0** |

总分 = 六维之和。stub 可评分进 TOP3，但永不自动主写。

## 指定模式阈值

对**用户点名的风格**相对选题打分：

| 分数 | full 风格 | stub 风格 |
|------|-----------|-----------|
| ≥40/60 | 按该风格生成 | 软切换最近 full + brief 说明 |
| 30–39 | 仍可生成，brief 注明非最优 | 软切换 |
| ＜30 或落入禁区（任一维=0） | **软切换**到最高分 full，brief 说明原因（本批不硬中断交稿） | 软切换 |

混搭两种及以上 → **硬拒绝混搭**（不写伪混搭正文）。
