# Brief 模板与问卷

## ask_user_question 建议题集

一次收集（可压缩为 4–6 题）：

| 问题 | 类型 | 说明 |
|------|------|------|
| 这次推广什么？ | 文本 | 产品/活动/主题一句话 |
| 给谁看？ | 文本 | 受众画像 |
| 语气 | 单选或多选 | 专业 / 活泼 / 干货 / 促销 |
| 发到哪些平台？ | 多选 | 8 平台中文名；默认全选可一键 |
| 要不要小红书多图轮播？ | 是/否 | 是则阶段 5 走 od-social-carousel |
| 现在要不要发布？ | 单选 | 只出文件 / 存草稿 / 公开（默认：只出文件） |

## brief.md 落盘格式

```markdown
# Campaign Brief: <slug>

## 主题
...

## 受众
...

## 语气
...

## 目标平台
- [ ] 小红书
- [ ] 抖音
...

## CTA
...

## 发布意图
- [ ] 仅交付文件（默认）
- [ ] 存平台草稿
- [ ] 公开上线（需用户明确）

## 可选
- 多图轮播：是/否
- 品牌色/禁用项：...
```

## 创意锚点（阶段 2 另文件）

写入 `creative-anchor.md`：

- **valueProp**：一句话价值主张
- **visualPrompt**：给 `generate_image` 的完整画面描述（主体、构图、光线、风格、无文字或少量文字）
- **tone**：与 brief 一致
- **cta**：行动号召
- **avoid**：禁用元素（竞品 logo、敏感词等）
