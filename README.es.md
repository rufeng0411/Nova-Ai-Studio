# Nova Ai-Studio

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md)

Edición comunitaria **AGPL**: un banco de trabajo Agent en tu máquina. La conversación entrega archivos, no un chat. Texto completo: [English README](README.md) · [简体中文](README.zh-CN.md).

```bash
cp .env.example .env
corepack enable
pnpm install
pnpm run dev
```

URL de Vite → `/login` → `admin` + `SAAS_ADMIN_PASSWORD` → mesa de trabajo.
