Mesa de Agent conversacional autoalojada. SaaS personal: solo inicio de sesión.

Full docs: [English README](README.md) · [简体中文](README.zh-CN.md)

```bash
cp .env.example .env
corepack enable
pnpm install
pnpm run dev
```

Open the Vite URL → `/login` → `admin` + `SAAS_ADMIN_PASSWORD` → `/app`.
